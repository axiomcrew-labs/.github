# .github
Organization profile and public resources for AxiomCrew Labs.

## Community issue templates / 社区 Issue 模板

This repository provides three bilingual default issue forms for AxiomCrew Labs projects:

- **Bug report / 问题反馈** — version, environment, reproduction steps, expected and actual behavior.
- **Feature request / 功能建议** — use case, problem, and proposed improvement.
- **Documentation / 文档反馈** — document location, unclear or incorrect content, and suggested changes.

Forms are stored in `.github/ISSUE_TEMPLATE/`. The blank issue entry remains enabled. Contributors can answer in English or Chinese. These defaults do not assign people or require project-specific labels.

本仓库为组织项目提供三个中英文默认表单，保留空白 Issue 入口。核心信息必填，补充材料选填，可使用中文或英文填写；模板不绑定特定项目、负责人或标签。

A repository with its own valid issue templates or issue-template configuration overrides the entire organization default set. See [GitHub's inheritance rules](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file).

项目仓库配置自己的有效模板或模板配置后，会整体覆盖组织默认模板。请在相关项目仓库提交该项目的问题。
