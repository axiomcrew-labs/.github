# AxiomCrew Labs

**Human direction. AI collaboration.**  
**人来定方向，AI 来协作。**

AxiomCrew Labs is an independent AI engineering initiative exploring practical tools for individual builders and small teams.

## What we explore

- **Ontology-driven AI** — explicit concepts, relationships, and constraints for shared meaning and context.
- **Agent collaboration** — clear roles, task handoffs, review, and recoverable workflows.
- **Local AI** — tools and experiments for running AI closer to the people and systems that use it.
- **Developer tooling** — reusable skills, integrations, and engineering practices grounded in real projects.

## First project: OneDevCrew

**One developer. An AI crew.**

OneDevCrew is being prepared for its first open-source release. It is a multi-agent development toolkit for solo developers and small teams, with an initial focus on Claude Code and GitHub Issues / pull requests.

The planned first release connects planning, implementation, review, and delivery while keeping people in control of important decisions.

**Status: design and open-source preparation.** The project repository, installation guide, and reproducible examples will be linked here when available.

## How we work

- **Build from real problems.** Start with a concrete task and a useful outcome.
- **Make results inspectable.** Keep changes, tests, decisions, and limitations visible.
- **Keep humans involved.** Make scope, tradeoffs, and release decisions explicit.
- **Share the learning.** Publish practical examples, engineering notes, and honest retrospectives as projects develop.

Follow this organization for project releases and development notes.

## 关于 AxiomCrew Labs

AxiomCrew Labs 是一个独立的 AI 工程实践与开源探索组织，关注个人开发者和小团队如何把 AI 用到实际工作中。

我们探索四个方向：**本体驱动 AI、多 Agent 协作、本地 AI、开发者工具**。通过具体项目沉淀可复用的方法，并公开记录实现过程、验证结果、使用成本与失败经验。

### OneDevCrew

OneDevCrew 是我们的首个重点项目：面向个人开发者和小团队的多 Agent 研发协作工具包，首版计划基于 Claude Code，以 GitHub Issues 和 PR 串联需求、开发、审查与交付。

项目目前处于**设计与开源准备阶段**。仓库、安装说明和可复现示例发布后，将在这里更新入口。

后续内容将围绕项目实践、版本进展与技术复盘展开，也会逐步介绍本体与本地 AI 相关探索。

### 我们关注的方向

- **本体驱动 AI**：用明确的概念、关系和约束建立共享语义与上下文。
- **多 Agent 协作**：清晰的角色分工、任务交接、审查与可恢复流程。
- **本地 AI**：探索更贴近用户及其系统运行的 AI 工具与实践。
- **开发者工具**：从真实项目中沉淀可复用的技能、集成与工程方法。
